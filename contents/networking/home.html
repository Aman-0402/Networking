📘 Networking eBook

Learn Networking step by step

Module 1: Standards and Concepts

1.1 Fundamental Networking Building Blocks

Learn the core foundations of networking including TCP/IP model, OSI model, frames vs packets, and addressing concepts.

1.2 Bandwidth vs Throughput

Understand network performance concepts like bandwidth, throughput, latency, delay, and tools like Speed Test and iPerf.

1.3 Network Types & Topologies

Explore LAN, WAN, MAN, CAN, PAN, WLAN and learn physical and logical network topologies.

1.4 Cloud vs On-Premises Services

Compare public, private, and hybrid cloud models, SaaS, PaaS, IaaS, and modern remote/hybrid work environments.

1.5 Network Applications & Protocols

Learn how TCP vs UDP works and understand key protocols like FTP, HTTP, DHCP, DNS, ICMP, and NTP.

Module 2: Addressing and Subnet Formats

2.1 Private vs Public IP Addressing

Understand private and public IP addressing, address classes, and how NAT enables internal networks to access the internet.

2.2 IPv4 Addressing & Subnetting

Learn subnet concepts including CIDR (slash notation), subnet masks, broadcast domains, and how subnet calculators work.

2.3 IPv6 Addressing

Explore IPv6 address structure, address types, and prefix formats designed to replace IPv4.

Module 3: Endpoints and Media Types

3.1 Network Cables and Connectors

Learn about cable types such as fiber, copper, and twisted pair, along with common connectors like RJ-45, RJ-11, coax, and fiber connectors.

3.2 Network Technologies

Understand wired and wireless networking technologies including Wi-Fi bands (2.4GHz, 5GHz, 6GHz), cellular networks, and interference sources.

3.3 Endpoint Devices

Explore common endpoint devices such as IoT devices, computers, mobile devices, IP phones, printers, and servers.

3.4 Network Connectivity Setup & Checks

Learn how to configure and verify network connectivity across Windows, Linux, macOS, Android, and iOS using networking utilities and wireless settings.

Module 4: Infrastructure

4.1 Cisco Device Status Indicators

Learn how to interpret Cisco device LED indicators, including link light colors and blinking versus solid states.

4.2 Cabling Using Network Diagrams

Understand network cabling using diagrams, including patch cables, switches, routers, small topologies, and power or rack layouts.

4.3 Network Device Ports

Explore common network ports such as console, serial, Ethernet, fiber, SFPs, USB ports, and Power over Ethernet (PoE).

4.4 Routing Fundamentals

Learn routing basics including default gateways, Layer 2 vs Layer 3 devices, and how local and remote networks communicate.

4.5 Switching Fundamentals

Understand switching concepts such as MAC address tables, MAC filtering, and VLAN fundamentals.

Module 5: Diagnosing Problems

5.1 Troubleshooting & Help Desk Practices

Learn structured troubleshooting approaches including ticketing systems, documentation, information gathering, and issue prioritization.

5.2 Packet Capture

Understand packet capture concepts using Wireshark, including capturing traffic and saving or opening .pcap files.

5.3 Diagnostic Commands

Learn essential diagnostic commands such as ping, ipconfig, ifconfig, tracert, traceroute, nslookup, and firewall behavior analysis.

5.4 Device Access & Data Collection

Explore methods to access devices using RDP, SSH, Telnet, VPN, console connections, network management systems, cloud-managed networks, and scripts.

5.5 Cisco Device Show Commands

Learn essential Cisco IOS show commands, privilege levels, and command help features for effective network diagnostics.

Module 6: Security

6.1 Firewall Fundamentals

Learn how firewalls filter network traffic using port and protocol rules, and understand permit versus deny security policies.

6.2 Core Security Concepts

Understand CIA triad, AAA, multi-factor authentication, encryption, certificates, password policies, identity stores, and common cyber threats.

6.3 Wireless Security Configuration

Learn wireless security standards including WPA, WPA2, and WPA3, personal vs enterprise security, and home router best practices.
